# DigitalRezeki Rental System v1.0

## Deskripsi

DigitalRezeki Rental System adalah aplikasi manajemen rental komputer berbasis Python Flask yang dirancang untuk membantu operasional usaha rental komputer secara cepat, mudah, dan terintegrasi.

## Fitur Utama

* Login Multi User
* Dashboard Monitoring
* Manajemen Member
* Topup Saldo
* Rental Komputer
* Timer Realtime
* Cetak Struk
* Laporan Transaksi
* Laporan Harian
* Export Excel
* Export PDF
* Audit Log
* Backup Database
* Grafik Pendapatan

## Teknologi

* Python 3.14
* Flask
* SQLite
* Bootstrap 5
* Chart.js
* OpenPyXL
* ReportLab
